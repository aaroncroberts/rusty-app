## Contributing to Documentation

When adding new documentation:

1. Place it in the appropriate subdirectory under `docs/`
2. Update this README with a link to the new documentation
3. Use clear, professional markdown formatting
4. Include code examples where applicable
5. Keep documentation up-to-date with code changes

## Documentation Standards

- Use clear, concise language
- Include practical examples
- Organize content with proper headings
- Use code blocks with syntax highlighting
- Link to related documentation
- Keep line lengths reasonable (80-100 characters)
- Use tables for structured data
